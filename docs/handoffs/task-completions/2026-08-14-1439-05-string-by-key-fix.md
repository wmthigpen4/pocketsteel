# String By Play-Along Key Fix

## Task Summary

- Fixed the Play Along analyzer failure that changed the supplied A-flat song
  into a long false E-flat region.
- Kept key-region scoring anchored to the chord candidate led by the audio,
  reduced the ability of a proposed key to rewrite a competing chord root, and
  raised the minimum stable key-region length from six to eight bars.
- Added deterministic regression coverage for dominant-heavy A-flat harmony

## Root Cause And Correction

The global detector already preferred A-flat, but `keyEvidenceScore` allowed a
proposed section key to select a weaker chord candidate after applying that
same key's harmonic prior. In the supplied recording, provisional E-flat
context could therefore reinterpret audio-leading B-flat minor as B-flat major
and then use that rewrite as further evidence for E-flat.

The correction makes key-region evidence use the audio-leading chord candidate,
weights the decoder key prior at `0.35`, and prevents context from changing to
a different root when the audio-leading candidate is at least `0.04` stronger.
An eight-bar minimum also rejects the remaining short false-region edge case
while preserving the existing thirteen-bar genuine-modulation fixture.
