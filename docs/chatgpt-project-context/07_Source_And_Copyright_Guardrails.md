# 07 Source And Copyright Guardrails

## Provenance Categories

### Deterministic Exercise

Use for original drills, grips, chord moves, short licks, and practice phrases generated from E9 rules.

Requirements:

- no external source claim,
- no SGF tab copied into generated output,
- no public-domain song implication,
- clear deterministic/original educational framing.

### Source-Backed SGF / Lesson-Inspired Idea

Use when sources support a general teaching idea, technique, gear point, or forum wisdom.

Requirements:

- paraphrase and synthesize,
- source cards support claims below the answer,
- raw SGF fragments must not become primary answer text,
- generated tab remains original unless exact public-domain source data supports it.

### Public-Domain Song Arrangement

Use only when a documented public-domain song record exists.

Requirements:

- verified public-domain status,
- explicit source/publication basis,
- melody/chord data stored or cited,
- source citation,
- deterministic arrangement id/version,
- validation before display.

## Blocked Requests

Block or redirect:

- full copyrighted song tabs,
- full solo transcription,
- recording or YouTube transcription,
- modern copyrighted arrangements,
- named-artist solo reconstruction,
- requests to copy paid/private lesson transcript material,
- requests that require private source text outside approved auth/provenance controls.

Safe alternatives:

- explain the technique,
- offer a short original exercise,
- show a public-domain or user-provided example when provenance is explicit,
- ask the user to provide notes/chords they own or have permission to use.

## Public-Domain Song Requirements

Before generating public-domain song tab, the system needs:

- explicit song id,
- rights status,
- review basis,
- source citation,
- melody or chord source data,
- supported key and arrangement type,
- validation output,
- UI/source-card provenance.

Do not infer public-domain status at answer time from a song title alone.

## SGF / Source-Backed Guidance

SGF retrieval can support forum wisdom, tone, gear, maintenance, and community practice advice. It should not be used as raw primary answer text.

For deterministic E9 mechanics, prefer rules and validated fretboard/tab logic over retrieval. Source cards may appear only as secondary context when they are relevant and not misleading.

## Private / Paid Lesson Transcript Caution

Private or paid source material must stay behind the correct auth and review controls.

Do not upload, paste, or summarize large private source bodies into project files, prompts, handoffs, source cards, or public answers. Use short metadata, provenance records, and protected retrieval summaries only when approved.
