Explorer glossary

Copedent
The tuning and pedal/lever changes on a pedal steel.
Diatonic harmony
Chords built from the notes of one key or scale.
Harmonized scale
A scale played as paired or grouped notes instead of single notes.
Diminished
A tense chord built from stacked minor-thirds; often shown with °.
Half-diminished
A minor seven flat five sound; often shown as m7b5 or ø.
m7b5
Means minor seven flat five. It is another common label for half-diminished.
ø
The half-diminished symbol. It usually means the same sound as m7b5.
°
The diminished symbol. In a scale-degree label, vii° means the diminished chord built on the seventh scale degree.
Partial row
A row that does not contain every chord tone by itself. Use the warning text to see whether it is partial diminished, partial m7b5, rootless, or needs musical context.
Core grip
A beginner-friendly string set used for the default Explorer and harmonized-scale views.
Path grip
A string set used to keep harmonized movement connected inside a pocket.
Extended grip
A real-world tab or voicing-discovery grip, often wider or less direct than the beginner core grips.
Song/tab vocabulary grip
A context-dependent grip seen in real playing vocabulary. It is calculated and explained, but not treated as a beginner default.
E-lower pocket
A grip whose practical value depends on the E-lower lever; 5-7-8 is the required pocket case.
Two-string grip / dyad
A two-note grip. It may function as harmony, a partial chord, a pad, or passing color depending on context.
Pad / sustain
A held support sound, often two or more strings, used underneath or around moving melody notes.
Partial voicing
A useful part of a chord that does not include every chord tone by itself.
NNS / Nashville Number System
Number names for scale degrees and chords, so a pattern moves between keys.
Notation mode
Choose notes, Nashville numbers, Roman numerals, or number-plus-quality labels for cards and markers.
Scientific octave notation
A register naming system where middle C is C4. On standard E9, string 4 is E4 and string 8 is E3.
Pitch register
The octave location of a pitch, tracked separately from the pitch class so chord names still use notes like G, B, and D.
Octave band
A simplified register label: lower, middle, or upper. It helps compare where the same note appears on the E9 neck.
Peterson octave labels
Device-specific labels such as 1 Oct. or 2 Oct. need verified manual mapping before this Explorer displays them.
NNS
Nashville-style numbers, such as 1, 2-, 3-, 4, 5, 6-, and 7° in a major key.
Roman
Roman numerals with chord quality, such as I, ii, iii, IV, V, vi, and vii°.
Top note interval
The selected notation label carried by the highest selected string in a grip.
Top note
The letter note on the highest selected string in a grip.
Flat symbol
♭ means the note or interval is lowered, so ♭3 means flat third and ♭7 means flat seventh.
Flat 7 / ♭7
The lowered seventh note of a chord or scale. It is the note that gives a dominant 7 chord its pull.
Dominant 7
A major chord with a flat 7 added. In key-based playing, the dominant 7 chord creates pull back to I.
V7
The dominant 7 chord built on the fifth scale degree. In G, V7 is D7: D, F#, A, C.
9th string
On standard E9, the 9th string is D. It is often useful for dominant-7 and passing-color grips.
Notes
The letter names being played, such as G, B, or D.
Grips
Common sets of strings picked together.
Pedals
Foot controls that raise or lower selected strings.
Levers
Knee controls that raise or lower selected strings.
Root
The home note or chord name that the other notes relate to.
Inversion
The same chord tones with a note other than the root on top or bottom.
String group
The selected set of strings used for a row, such as 4-5-6.
